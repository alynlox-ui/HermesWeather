HERMES WEATHER 补丁更新报告

客户端外壳：v1.4.4（versionCode 10）
补丁版本：1.4.4-p2
发布日期：2026-08-04
更新方式：HTTPS 前端热补丁，无需重新安装 APK

修复 1：上传自定义背景后任务栏透明度显示错误
- 原因：自定义背景样式把侧栏固定写成 90% 不透明，移动 Dock 又固定写成 96%，覆盖了用户设置。
- 修复：桌面任务栏、移动 Dock 与所有背景面板统一读取 --panel-alpha；上传背景不再改变透明度。
- 验证：预置透明度 37% 并启用自定义背景后，任务栏 rgba alpha=0.37，天气卡片 alpha=0.37。

修复 2：部分 UI 色彩匹配异常
- 原因：部分按钮、边框、开关、Toast 和交互状态仍使用固定绿色或固定暗色，没有跟随自定义强调色和明暗主题。
- 修复：新增语义色变量 accent-soft、accent-border、chart-secondary；导航、按钮、输入焦点、开关、提示和浅色模式卡片统一匹配当前强调色及主题。
- 验证：选择 #d49cff 后 CSS --green=#d49cff，预设选中态和交互控件均跟随该强调色。

修复 3：设置中的透明度保存后自动恢复默认
- 原因：旧数据类型缺少归一化，并且只在 change 事件写入；Android 拖动结束或页面切换时可能没有触发，重新载入后回到 88%。
- 修复：启动时规范化并迁移旧设置；input 实时写入，change、pointerup、touchend 和 pagehide 再次持久化；applyPrefs 统一回填控件。
- 验证：旧字符串值“37”载入后显示 37%/alpha 0.37；拖到 43 时 localStorage 在 input 阶段已保存为 43。

修复 4：Android 底部 Dock 响应过慢
- 原因：只监听 click，Android WebView 需要等待完整触摸点击合成后才切换视图。
- 修复：触摸笔/手指 pointerdown 立即切换，阻止重复 click；增加 touch-action:manipulation、移除点击高亮并提供按压反馈。
- 验证：模拟 pointerdown 后天气、地点、趋势、设置立即依次切换到 weatherView、placesView、trendsView、settingsView。
