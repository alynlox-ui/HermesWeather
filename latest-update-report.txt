HERMES WEATHER 统一更新报告

客户端：v1.4.5（versionCode 11）
前端补丁：1.4.5-p1
发布日期：2026-08-04

修复 1：标签页模糊度过高且修改无效
- 移除卡片、顶部栏、Dock 和设置行的 backdrop-filter 模糊，模糊滑块现在只作用于用户上传的背景图。
- 模糊范围由 0–20 调整为 0–12，避免过度模糊。
- 使用 SVG Gaussian Blur 节点更新 stdDeviation，绕过 WebView CSS filter 更新异常。
- input 阶段实时更新并保存，change/pointerup/touchend 再次持久化。
- 验证：滑块设置8时，SVG stdDeviation=8、显示8px、本地存储bgBlur=8；卡片 backdrop-filter=none。

修复 2：启动自动请求定位
- v1.4.5 Manifest 新增 ACCESS_COARSE_LOCATION 与 ACCESS_FINE_LOCATION。
- 应用首次启动立即显示 Android 定位权限请求。
- WebChromeClient 接管 WebView GeolocationPermissions 并仅在系统权限已授予时放行。
- 网页首次启动自动调用 useCurrentLocation；授权后查询坐标、反向地理编码及天气。
- 拒绝、系统定位不可用或超时会显示明确错误，仍保留“使用当前位置”按钮供再次尝试。
- 这是原生权限变化，因此 v1.4.4 必须覆盖安装一次 v1.4.5；之后前端更新继续使用热补丁。

修复 3：小字可读性降低
- 次要文字统一提高到至少12px、font-weight 500/600、line-height 1.55。
- 自定义背景下提高说明文字亮度并添加暗色文字阴影，不增加卡片不透明度。
- Dock 标签提升至12px并强化未选中颜色。
- 卡片边框和控件轮廓增强，低透明度下仍可识别。
- 增加移动底部留白，避免 Dock 遮挡最后一项设置。
