# Hermes Weather

Hermes Weather 是一款支持桌面、Android 与网页端的天气应用。

## 在线网页版

https://alynlox-ui.github.io/HermesWeather/

网页版无需下载安装，可直接在现代浏览器中使用。地点搜索、天气预报、收藏、历史、趋势图、主题、透明度、本地背景及天气动画均在浏览器内运行；偏好和背景仅保存在本机浏览器中。

## 数据与隐私

天气和地点数据来自 Open-Meteo。网页不包含密钥，不设服务器端账户，也不会上传用户选择的本地背景。
